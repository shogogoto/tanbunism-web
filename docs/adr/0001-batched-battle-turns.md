# 戦闘ターンはブラウザで操作し、終了時にまとめて保存する

回答操作のリアルタイム性を優先し、複数敵のクイズは共通の持ち時間内にブラウザで切り替えて回答する。各回答は一度確定したら変更できず、全問回答または時間切れでターンを終了してダメージを一括精算し、実際に回答した問題だけ復習履歴・XPとともにまとめて保存する。回答途中の状態は保存せず、未完了の戦闘を開き直した場合は未保存ターンを全問未回答として撤退扱いにする。

## Consequences

- 未回答の不正解扱いは戦闘ダメージだけであり、復習履歴に誤答として記録せず、復習XPも付けない。
- 開き直した未保存ターンの回答履歴・XPは失われる。終了して保存済みのターンは失わない。
- 通常の明示的な撤退は確定済み回答を精算し、未回答を不正解相当のダメージとして扱う。撤退では戦闘前の地点へ戻り、消費した歩数と開拓履歴は維持する。HPが0なら通常の冒険失敗とする。
- 戦闘中はステータス編集不可。相打ちもプレイヤーの敗北とする。

複数敵の戦闘で実装。敵の固定ID・固定クイズ・生存IDと戦闘前の地点を保存し、残HP・選択途中の答えはブラウザのメモリだけに置く。ターン精算と回答・XPは同じトランザクションで保存し、直近の精算receiptで通信再送の二重記録を防ぐ。

敵の能力は現在のリソースPower・クイズ対象単文の関係数・adminの補正から導出する。旧保存の敵HP/攻は使わない。画面は30秒ごと/フォーカス復帰で再取得し、精算時は最新の値を使用する。最大HPが変わっても残HPを回復させない。共通の持ち時間はターン開始時に確定する。
